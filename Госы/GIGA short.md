# Базовый курс высшей математики: фундаментальные разделы и ключевые понятия

## Введение
Высшая математика представляет собой единый аппарат, связывающий аналитические методы, алгебраические структуры и вероятностные модели в систему, позволяющую описывать, анализировать и прогнозировать поведение реальных процессов. Ниже приведён структурированный обзор базовых разделов, которые составляют математический фундамент инженерных и IT-специальностей. Материал скомпонован не по билетам, а по логике развития понятий: от пределов и производных до рядов, дифференциальных уравнений и вероятностных моделей.

---

## 1. Математический анализ

### 1.1 Пределы и непрерывность
- **Предел последовательности** `{xₙ}`: число `a` называется пределом, если `∀ε>0 ∃N: ∀n>N → |xₙ − a| < ε`. Сходящиеся последовательности обладают свойством единственности предела и удовлетворяют **критерию Коши**: `∀ε>0 ∃N: ∀n,m>N → |xₙ − xₘ| < ε`.
- **Предел функции** `limₓ→ₐ f(x) = A`: формализуется через `ε-δ` определение. Важнейшие инструменты раскрытия неопределённостей `0/0` и `∞/∞` — **первый** `limₓ→₀ sin x/x = 1` и **второй** `limₓ→∞ (1+1/x)ˣ = e` замечательные пределы, а также **правило Лопиталя**: при условиях дифференцируемости и существования предела `lim f(x)/g(x) = lim f'(x)/g'(x)`.

### 1.2 Дифференциальное исчисление
- **Производная** `f'(x₀) = lim_Δx→₀ [f(x₀+Δx)−f(x₀)]/Δx` характеризует мгновенную скорость изменения функции. Геометрически равна угловому коэффициенту касательной, физически — скорости процесса.
- **Дифференциал** `dy = f'(x)dx` — главная линейная часть приращения функции. Используется для приближённых вычислений и линеаризации.
- **Дифференцирование сложных, обратных, неявных и параметрически заданных функций** строится на цепном правиле `(f(g(x)))' = f'(g(x))·g'(x)` и неявном дифференцировании уравнения `F(x,y)=0`.
- **Многомерный случай**: частные производные `∂z/∂x`, `∂z/∂y` находятся при фиксировании остальных переменных. Полный дифференциал `dz = (∂z/∂x)dx + (∂z/∂y)dy`. **Градиент** `grad z = (∂z/∂x, ∂z/∂y)` указывает направление наискорейшего роста функции, а производная по направлению `∂z/∂l = ∇z·ē` равна проекции градиента на единичный вектор направления.

### 1.3 Интегральное исчисление
- **Неопределённый интеграл** `∫f(x)dx = F(x)+C` — множество первообразных. Основные методы: замена переменной, интегрирование по частям, разложение на простейшие дроби (рациональные функции), подстановки для иррациональных выражений.
- **Определённый интеграл** `∫ₐᵇ f(x)dx` вычисляется по формуле Ньютона–Лейбница `F(b)−F(a)`. Свойства линейности, аддитивности по отрезку, теорема о среднем, критерий интегрируемости Римана.
- **Двойной интеграл** `∬_R f(x,y)dxdy` сводится к повторному по теореме Фубини, позволяет находить объёмы тел, площади поверхностей, массы пластин.

### 1.4 Исследование функций
Полный анализ включает:
1. Область определения и точки разрыва.
2. Четность/нечетность, периодичность.
3. Интервалы монотонности (`f'>0` → возрастание, `f'<0` → убывание).
4. Экстремумы: необходимое условие `f'(x₀)=0` или не существует; достаточные условия через смену знака производной или знак второй производной.
5. Выпуклость/вогнутость (`f''>0` → выпукла вниз), точки перегиба.
6. Асимптоты (вертикальные, наклонные, горизонтальные).
Ключевые теоремы: **Ферма** (в экстремуме производная нулевая), **Ролль** (существует точка с нулевой производной на отрезке с равными концами), **Лагранж** `f(b)−f(a)=f'(ξ)(b−a)` — основа для оценок и доказательств.

## 2. Дифференциальные уравнения

- **Уравнения 1-го порядка**:
  - С разделяющимися переменными: `y'=f(x)g(y) → ∫dy/g(y) = ∫f(x)dx`.
  - Однородные: `y'=φ(y/x)`, замена `y=ux`.
  - В полных дифференциалах: `Pdx+Qdy=0`, где `∂P/∂y=∂Q/∂x`. Решается через потенциал `U(x,y)=C`.
- **Линейные уравнения n-го порядка**:
  - Однородные с постоянными коэффициентами: характеристическое уравнение `aₙλⁿ+…+a₀=0`. Типы корней определяют вид общего решения (экспоненты, синусы/косинусы, полиномиальные множители при кратных корнях).
  - Неоднородные: общее решение `y = y_одн + y_част`. Частное решение находится методом **вариации постоянных** (универсальный) или методом **неопределённых коэффициентов** (при специальном виде правой части: многочлены, экспоненты, тригонометрия).

---

## 3. Линейная алгебра

- **Матрицы и определители**: операции сложения, умножения на число, произведения матриц, транспонирование. Определитель раскладывается по строке/столбцу (теорема Лапласа). Ранг матрицы — порядок максимального ненулевого минора.
- **СЛАУ**: 
  - Метод Крамера (при `Δ≠0`).
  - Метод Гаусса (приведение расширенной матрицы к ступенчатому виду). Теорема Кронекера–Капелли: система совместна ⇔ `rank A = rank Ā`.
- **Собственные значения и векторы**: `A·v = λv`. Находятся из `det(A−λE)=0`. Базис из собственных векторов позволяет диагонализировать матрицу (если существует).
- **Квадратичные формы**: `Q(x) = xᵀAx`. Приводятся к каноническому виду `∑αᵢyᵢ²` невырожденными линейными заменами. Метод Лагранжа (выделение полных квадратов) или ортогональное приведение к главным осям (через собственные значения симметричной матрицы `A`). Закон инерции: число положительных/отрицательных коэффициентов инвариантно.

---

## 4. Числовые и степенные ряды

- **Числовые ряды** `∑aₙ`: сходимость ⇔ сходимость последовательности частичных сумм. Критерий Коши для рядов. Признаки сходимости для положительных рядов: сравнения, Даламбера `lim|aₙ₊₁/aₙ|`, радикальный Коши `limⁿ√|aₙ|`, интегральный признак Коши. Знакопеременные ряды: признак Лейбница (монотонное убывание к нулю ⇒ сходимость). Абсолютная сходимость ⇒ обычная сходимость. Условно сходящиеся ряды можно переставить так, чтобы сумма стала любой (теорема Римана).
- **Степенные ряды** `∑cₙ(x−x₀)ⁿ`: интервал сходимости `(x₀−R, x₀+R)`, радиус `R = 1/limⁿ√|cₙ|` или `lim|cₙ/cₙ₊₁|`. Внутри интервала ряд сходится равномерно, допускает почленное дифференцирование и интегрирование. Разложение элементарных функций в ряды Тейлора/Маклорена позволяет аппроксимировать функции, вычислять интегралы и решать дифференциальные уравнения вблизи точки.

---

## 5. Теория вероятностей (базис)

- **Условная вероятность** `P(A|B)=P(A∩B)/P(B)`. Формула полной вероятности: `P(A)=∑P(Hᵢ)P(A|Hᵢ)`. Формула Байеса: апостериорная вероятность гипотезы `P(Hᵢ|A) = [P(Hᵢ)P(A|Hᵢ)] / P(A)`.
- **Схема Бернулли**: `Pₙ(k)=Cₙᵏ pᵏ qⁿ⁻ᵏ`. При больших `n` применяются предельные теоремы: локальная Муавра–Лапласа `Pₙ(k)≈(1/√(npq))·φ((k−np)/√(npq))`, интегральная `P(k₁≤X≤k₂)≈Φ(x₂)−Φ(x₁)`, где `φ` и `Φ` — функции Гаусса и Лапласа.
- **Случайные величины**:
  - Дискретные: задаются рядом распределения `P(X=xᵢ)=pᵢ`, `∑pᵢ=1`.
  - Непрерывные: задаются функцией распределения `F(x)=P(X<x)` и плотностью `f(x)=F'(x)`, `∫f(x)dx=1`.
- **Числовые характеристики**: математическое ожидание `M(X)` (центр распределения), дисперсия `D(X)=M[(X−M(X))²]` (мера разброса), среднее квадратическое отклонение `σ=√D(X)`. Для суммы независимых СВ: `M(∑Xᵢ)=∑M(Xᵢ)`, `D(∑Xᵢ)=∑D(Xᵢ)`.

## Заключение: логические связи и рекомендации

1. **Единая нить**: пределы → производные → интегралы → дифференциальные уравнения. Алгебра матриц → СЛАУ → собственные значения → квадратичные формы → анализ экстремумов функций многих переменных. Вероятность → статистика → стохастические модели в ИТ и телекоме.
2. **Типовые ошибки на экзамене**:
   - Путаница между необходимым и достаточным условиями (например, `f'(x₀)=0` необходимо, но не достаточно для экстремума).
   - Ошибки в знаках при интегрировании по частям или замене переменной.
   - Забывание проверять сходимость на концах интервала степенного ряда.
   - Неправильное приведение СЛАУ к ступенчатому виду (потеря строк, арифметика).
   - В вероятности: применение формул Байеса без проверки полной группы гипотез.
3. **Стратегия подготовки**:
   - Выучить определения *дословно* (предел, производная, дифференциал, сходимость ряда, функция распределения).
   - Отработать типовые задачи: исследование функции, интегрирование рациональных/иррациональных выражений, решение СЛАУ, нахождение собственных значений, проверка сходимости ряда, вычисление вероятностей по схемам Бернулли и Байеса.
   - Связывать формулы с геометрическим/физическим смыслом: это резко повышает устойчивость памяти под стрессом.

## 📐 МАТЕМАТИЧЕСКИЙ АНАЛИЗ

### Пределы
| Понятие | Формула/Определение |
|---------|-------------------|
| Предел последовательности | `∀ε>0 ∃N: n>N → \|xₙ−a\|<ε` |
| Критерий Коши | `∀ε>0 ∃N: ∀n,m>N → \|xₙ−xₘ\|<ε` |
| 1-й замечательный | `limₓ→₀ sinx/x = 1` |
| 2-й замечательный | `limₓ→∞ (1+1/x)ˣ = e` |
| Правило Лопиталя | `0/0 или ∞/∞: lim f/g = lim f'/g'` |

### Производные
```
f'(x₀) = lim_Δx→₀ [f(x₀+Δx)−f(x₀)]/Δx
dy = f'(x)dx  (дифференциал)
```
**Правила**: `(uv)'=u'v+uv'`, `(u/v)'=(u'v−uv')/v²`, `(f(g(x)))'=f'(g)·g'`

### Интегралы
| Тип | Формула |
|-----|---------|
| Неопределённый | `∫f(x)dx = F(x)+C, F'=f` |
| Определённый | `∫ₐᵇ f(x)dx = F(b)−F(a)` (Ньютон-Лейбниц) |
| Замена переменной | `∫f(φ(x))φ'(x)dx = ∫f(u)du` |
| По частям | `∫udv = uv − ∫vdu` |
| Двойной | `∬_R f(x,y)dxdy = ∫(∫f dy)dx` (Фубини) |

### Теоремы анализа
- **Ферма**: если экстремум внутри и функция дифференцируема → `f'(x₀)=0`
- **Ролль**: `f(a)=f(b)` → `∃ξ∈(a,b): f'(ξ)=0`
- **Лагранж**: `f(b)−f(a)=f'(ξ)(b−a)`
- **Критерий интегрируемости**: функция интегрируема ⇔ верхняя и нижняя суммы Дарбу стремятся к одному пределу

## 🔢 ЛИНЕЙНАЯ АЛГЕБРА

### Матрицы
```
det(A·B) = det(A)·det(B)
det(A⁻¹) = 1/det(A)  (если det≠0)
rank(A) = max порядок ненулевого минора
```

### СЛАУ
| Метод | Условие | Формула |
|-------|---------|---------|
| Крамер | `det(A)≠0` | `xᵢ = Δᵢ/Δ` |
| Гаусс | Любая СЛАУ | Приведение к ступенчатому виду |
| Кронекер-Капелли | Совместность ⇔ `rank(A)=rank(Ā)` | — |

### Собственные значения
```
A·v = λ·v  →  det(A−λE)=0 (характеристическое уравнение)
```
- `tr(A)=Σλᵢ`, `det(A)=Πλᵢ`
- Симметричная матрица → вещественные λ, ортогональные векторы

### Квадратичные формы
```
Q(x) = xᵀAx  → канонический вид: Σαᵢyᵢ²
```
**Методы приведения**: Лагранжа (полные квадраты), ортогональное (через собственные значения)

## 📊 РЯДЫ И ВЕРОЯТНОСТИ

### Числовые ряды
| Признак | Условие сходимости |
|---------|-------------------|
| Необходимый | `lim aₙ = 0` (иначе расходится) |
| Сравнения | `aₙ≤bₙ`: сходимость ∑bₙ → сходимость ∑aₙ |
| Даламбера | `lim\|aₙ₊₁/aₙ\|=q`: q<1 → сходится |
| Коши | `lim ⁿ√\|aₙ\|=q`: q<1 → сходится |
| Лейбница | Знакочередующийся, \|aₙ\|↓0 → сходится |

### Степенные ряды
```
∑cₙ(x−x₀)ⁿ,  R = 1/lim ⁿ√\|cₙ\|  (радиус сходимости)
```
Внутри `(-R, R)` — можно дифференцировать/интегрировать почленно

### Вероятности
```
Условная: P(A\|B) = P(A∩B)/P(B)
Полная вероятность: P(A) = ΣP(Hᵢ)P(A\|Hᵢ)
Байес: P(Hᵢ\|A) = P(Hᵢ)P(A\|Hᵢ)/P(A)
```

### Схема Бернулли
```
Pₙ(k) = Cₙᵏ pᵏ qⁿ⁻ᵏ,  q=1−p
```
**Предельные теоремы** (при больших n):
- Локальная Лапласа: `Pₙ(k) ≈ (1/√(npq))·φ((k−np)/√(npq))`
- Интегральная: `P(k₁≤X≤k₂) ≈ Φ(x₂)−Φ(x₁)`

### Случайные величины
| Тип | Задание | Мат.ожидание | Дисперсия |
|-----|---------|-------------|-----------|
| Дискретная | `P(X=xᵢ)=pᵢ` | `M[X]=Σxᵢpᵢ` | `D[X]=M[X²]−(M[X])²` |
| Непрерывная | `F(x)=P(X<x), f(x)=F'(x)` | `M[X]=∫xf(x)dx` | `D[X]=∫(x−M)²f(x)dx` |

**Свойства**: `M[aX+b]=aM[X]+b`, `D[aX+b]=a²D[X]`, для независимых: `D[X+Y]=D[X]+D[Y]`

- **Прямая цепочка**: от фактов → к заключению (data-driven)
- **Обратная цепочка**: от гипотезы → к проверке условий (goal-driven)

### Нечёткие знания
```
Функция принадлежности: μₐ(x) ∈ [0,1]
Мамдани-вывод: агрегация → дефаззификация (центр масс)
```

## 🕸️ НЕЙРОННЫЕ СЕТИ

### Перцептрон
```
y = φ(Σwᵢxᵢ + b),  φ — активация (сигмоида, ReLU, tanh)
```

### Backpropagation (обратное распространение)
```
1. Прямой проход: вычислить выход и ошибку
2. Обратный проход: градиенты по цепному правилу
3. Обновление: w ← w − η·∂L/∂w
```

**Проблемы**: затухающие градиенты, локальные минимумы, переобучение  
**Решения**: ReLU, BatchNorm, Dropout, адаптивные оптимизаторы (Adam)

### Архитектуры
| Тип | Особенность | Применение |
|-----|------------|-----------|
| MLP | Полносвязные слои | Классификация, регрессия |
| CNN | Свертки + пулинг | Изображения, видео |
| RNN/LSTM | Память состояния | Временные ряды, текст |
| Transformer | Attention-механизм | NLP, большие модели |

### Деревья решений
```
Критерии разбиения: Information Gain, Gini Impurity
Плюсы: интерпретируемость, не требует масштабирования
Минусы: склонность к переобучению, нестабильность
```

## 🌐 СЕТИ И ТЕЛЕКОММУНИКАЦИИ

### Модель OSI (7 уровней)
```
7. Application — HTTP, FTP, SMTP
6. Presentation — шифрование, кодирование
5. Session — управление сеансами
4. Transport — TCP (надёжно), UDP (быстро)
3. Network — IP, маршрутизация
2. Data Link — MAC, Ethernet, коммутаторы
1. Physical — среда передачи, биты
```

### Коммутация
| Тип | Характеристика | Пример |
|-----|---------------|--------|
| Каналов | Выделенный путь на всё время сеанса | ТфОП |
| Пакетов (датаграммы) | Каждый пакет независимо, нет гарантий | IP/Internet |
| Пакетов (вирт. каналы) | Логическое соединение, порядок сохраняется | MPLS, ATM |

### TCP vs UDP
```
TCP: соединение, подтверждения, ретрансмиссии, контроль перегрузок → надёжно, но медленнее
UDP: без соединения, нет гарантий → быстро, для реального времени
```

### Адресация и протоколы
```
ARP: IP → MAC (в пределах подсети)
ICMP: служебные сообщения (ping, traceroute)
IPv4: 32 бита, CIDR-запись 192.168.1.0/24
```

### Физический уровень
| Среда | Плюсы | Минусы |
|-------|-------|--------|
| Витая пара | Дёшево, PoE | Помехи, ≤100м без усилителя |
| Оптоволокно | Гбит/с, нет ЭМП-помех, дальность | Дорогое оборудование, сложный монтаж |

**Модуляция**: BPSK(1 бит), QPSK(2 бита), 16-QAM(4 бита) на символ

## 🎲 МОДЕЛИРОВАНИЕ

### Дискретно-событийное моделирование
```
Компоненты: Сущность, Событие, Очередь, Ресурс, Статистика
Алгоритм: инициализация → цикл по событиям (мин. время) → обработка → статистика
```

### Генерация случайных величин
```
Равномерная: ξ ~ U[0,1] (стандартный генератор)
Экспоненциальная: η = −(1/λ)·ln(1−ξ)
Метод обратной функции: если есть F⁻¹, то X = F⁻¹(ξ)
```

### Оценка точности
```
Для вероятности: n ≥ z²·p(1−p)/ε²  (при неизвестном p берём p=0.5)
Для среднего: n ≥ (z·σ/ε)²
Доверительный интервал: θ̂ ± z·σ/√n
```

### Планирование экспериментов
- Последовательный анализ: адаптивное увеличение выборки
- Латинские гиперкубы: равномерное покрытие многомерного пространства
- Контрольные переменные: снижение дисперсии за счёт корреляции
