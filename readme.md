

### **1. `data_preprocessing.py`**
### **Описание скрипта обработки данных**

Этот скрипт занимается обработкой изображений и меток для дальнейшего использования в обучении модели. Он загружает изображения, преобразует их в нужный формат и сохраняет их в `.npy` файлы батчами.


### **Функции и их назначения**

1. **`process_batch(batch, label_mapping)`**
   - **Назначение**: Обрабатывает одну партию данных (батч) — изображения и их метки.
   - **Аргументы**:
     - `batch` (pandas DataFrame): Подмножество данных, которое содержит пути к изображениям и метки для одной партии.
     - `label_mapping` (dict): Словарь, который отображает метки (категории) в числовые значения.
   - **Возвращаемое значение**:
     - `images` (np.array): Массив обработанных изображений в формате `float16` с нормализацией (от 0 до 1).
     - `labels` (np.array): Массив числовых меток для каждой картинки в батче.

2. **`save_data_as_npy_batched()`**
   - **Назначение**: Загружает данные из CSV, разделяет их на обучающую и тестовую выборки, а затем сохраняет эти выборки в `.npy` файлы батчами.
   - **Аргументы**: Нет.
   - **Возвращаемое значение**: Нет.
   - **Шаги выполнения**:
     1. Загружает CSV файл с путями к изображениям и метками.
     2. Разбивает данные на обучающую и тестовую выборки с использованием `train_test_split` из библиотеки `sklearn`.
     3. Обрабатывает и сохраняет обучающие данные в батчах с размером `BATCH_SIZE`.
     4. Обрабатывает и сохраняет тестовые данные аналогично.
     5. Сохраняет изображения и их метки в `.npy` файлы в директории, указанной в `PROCESSED_DIR`.
     6. Выводит информацию о процессе обработки, включая размер батчей и маппинг меток.

### **Назначение**

Этот скрипт важен для эффективной подготовки данных для обучения модели, поскольку:
- Обработанные данные сохраняются в `.npy` файлы, которые удобно загружать в память без повторной обработки.
- Разбиение данных на батчи помогает избежать проблем с нехваткой памяти при работе с большими датасетами.
- Использование нормализации изображений и преобразования их в формат `float16` позволяет ускорить вычисления и снизить использование памяти.

### **Порядок работы**

1. Скрипт сначала создает папку для сохранения обработанных данных, если она не существует.
2. Затем из CSV файла загружаются пути к изображениям и соответствующие метки.
3. Данные делятся на обучающую и тестовую выборки с использованием `train_test_split`.
4. Далее скрипт обрабатывает каждую партию (батч) изображений, изменяя их размер, нормализуя и конвертируя в массивы `numpy`.
5. Сохраненные данные в `.npy` файлы используются в дальнейшем для обучения модели.



### **Дополнительные замечания**

- В процессе обработки изображений используются функции из `tensorflow.keras.preprocessing.image`, такие как `load_img` и `img_to_array`, для загрузки и преобразования изображений.
- Для нормализации изображений значения пикселей делятся на 255, что приводит к диапазону от 0 до 1.
- Для работы с метками используется маппинг, который отображает строковые метки в числовые значения, что необходимо для обучения модели.

### **3. `data_preprocessing.py`**
### **Описание скрипта загрузки данных с аугментацией и подготовкой к обучению**

Этот скрипт отвечает за загрузку данных, их аугментацию и создание батчей для обучения модели. В отличие от предыдущих шагов, где данные сохранялись в `.npy` файлы, здесь данные загружаются из файлов и обрабатываются на лету с использованием генераторов и TensorFlow `Dataset`.

### **Функции и их назначения**

1. **`load_batch(npy_file)`**
   - **Назначение**: Загружает данные из `.npy` файла, возвращая изображения и метки.
   - **Аргументы**:
     - `npy_file` (str): Путь к `.npy` файлу.
   - **Возвращаемое значение**:
     - `images` (np.array): Массив изображений.
     - `labels` (np.array): Массив меток для изображений.

2. **`data_generator(filenames, batch_size)`**
   - **Назначение**: Генерирует данные батчами для загрузки из файлов.
   - **Аргументы**:
     - `filenames` (list): Список путей к `.npy` файлам, содержащим данные.
     - `batch_size` (int): Размер батча.
   - **Возвращаемое значение**:
     - Генерирует батчи из изображений и меток.

3. **`create_dataset(file_list, batch_size, is_training=True)`**
   - **Назначение**: Создает `tf.data.Dataset` для загрузки данных батчами.
   - **Аргументы**:
     - `file_list` (list): Список файлов, из которых будет загружаться данные.
     - `batch_size` (int): Размер батча.
     - `is_training` (bool): Флаг, указывающий, используется ли данный датасет для обучения.
   - **Возвращаемое значение**:
     - Возвращает `tf.data.Dataset`, который можно использовать для обучения или тестирования модели.
   - **Дополнительные особенности**:
     - Если `is_training=True`, датасет будет перемешан.
     - Используется `prefetch` для ускорения процесса загрузки данных.

4. **`augment_data(images, labels)`**
   - **Назначение**: Применяет аугментацию данных (горизонтальный флип, вращение, увеличение) к изображениям.
   - **Аргументы**:
     - `images` (np.array): Массив изображений.
     - `labels` (np.array): Массив меток.
   - **Возвращаемое значение**:
     - Возвращает аугментированные изображения и метки.

5. **`get_data_loaders()`**
   - **Назначение**: Загружает данные и создает датасеты для обучения и тестирования.
   - **Аргументы**: Нет.
   - **Возвращаемое значение**:
     - Возвращает два объекта типа `tf.data.Dataset`:
       - `train_dataset` — датасет для обучения.
       - `test_dataset` — датасет для тестирования.

### **Назначение**

Этот скрипт используется для подготовки данных для обучения и тестирования модели:
- **Загрузка данных**: Используется генератор для загрузки данных по частям из файлов.
- **Аугментация**: Применяется аугментация для улучшения обобщающих способностей модели.
- **Создание `tf.data.Dataset`**: Данные подготавливаются для эффективной загрузки в TensorFlow, где они могут быть использованы для обучения модели.
- **Предобработка**: Батчи изображений и меток подготавливаются и передаются в модель, а данные могут быть случайным образом перемешаны для обучения.

### **Порядок работы**

1. Скрипт загружает все файлы `.npy`, которые были сохранены ранее.
2. Разделяет данные на обучающие и тестовые в соотношении 80/20.
3. Создает два датасета:
   - Для **обучения** с аугментацией.
   - Для **тестирования** без аугментации.
4. Эти датасеты затем могут быть использованы в тренировках модели.

### **Дополнительные замечания**

- **Аугментация данных**: Важно применять аугментацию только на обучающих данных, чтобы модель не научилась на изменениях, а обобщала.
- **Загрузка данных батчами**: Использование генераторов и `tf.data.Dataset` помогает обрабатывать большие объемы данных, не загружая все изображения в память сразу.
- **Prefetching**: Использование `dataset.prefetch` ускоряет процесс загрузки данных, что помогает при обучении модели на больших объемах данных.

### **8. `config.py`**
### **Описание скрипта конфигурации проекта**

Этот скрипт содержит основные параметры и настройки для проекта, такие как пути к данным, гиперпараметры для обучения модели и другие константы. Они будут использоваться в других частях проекта, чтобы обеспечить централизованное управление настройками.

### **Параметры и их назначения**

1. **Пути к данным**
   - `DATA_DIR` (str): Путь к директории, где хранятся исходные данные, такие как изображения и CSV-файлы. Например, можно указать путь к каталогу, где лежат исходные изображения для обучения и метки.
   - `PROCESSED_DIR` (str): Путь к директории, где будут сохраняться обработанные данные, такие как `.npy` файлы после предобработки. 
   - `MODEL_DIR` (str): Путь к директории, где будут сохраняться модели после обучения (например, веса модели).

2. **Гиперпараметры**
   - `IMG_SIZE` (int): Размер изображений для подачи в модель. Это определяет размерность изображений, которые будут передаваться в модель (например, 224x224 пикселей).
   - `BATCH_SIZE` (int): Размер батча для обучения модели, количество изображений в одном шаге обработки.
   - `EPOCHS` (int): Количество эпох для обучения модели. Означает, сколько раз модель будет проходить через весь тренировочный датасет.
   - `LEARNING_RATE` (float): Скорость обучения для оптимизатора, которая регулирует, насколько сильно модель будет обновлять свои веса в процессе обучения.
   - `TEST_SIZE` (float): Доля данных, которая будет использоваться для валидации (например, 0.2 означает 20% для валидации и 80% для обучения).

### **Назначение**

Этот файл служит для:
- Определения всех путей к данным и модельным файлам, чтобы не дублировать строки с путями в разных частях кода.
- Управления важными гиперпараметрами модели, такими как размер изображений, скорость обучения, количество эпох и размер батча.
- Упрощения изменения параметров проекта в одном месте, без необходимости изменять их в нескольких местах кода.
