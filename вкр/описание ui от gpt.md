1. Чётко определить роли.
2. Разделить hiring-режим и team-режим.
3. Прописать уровни доступа.
4. Отделить видеозвонок как core-экран.

# Предлагаемая структура для Figma Make

Ниже — улучшенный, системный вариант.

---

# UI для сервиса eMeeting

## 📌 Концепция

Enterprise meeting-платформа (аналог Google Meet) с интегрированным AI-модулем анализа эмоций:

* Анализ мимики и голоса
* Формирование метрик
* Использование в подборе персонала
* Аналитика командных созвонов

UI — минималистичный, корпоративный, SaaS-стиль, desktop-first.

---

# 👥 Роли пользователей

1. Администратор
2. HR
3. Руководитель
4. Сотрудник / Кандидат
5. Аналитик (только просмотр отчетов команд)

Это обязательно указать в промте.

---

# 🧭 Навигация

Sidebar:

* Dashboard
* Календарь
* Сеансы
* Отчеты
* Командная аналитика
* Пресеты AI (доступ ограничен)
* Настройки

---

# 1️⃣ Аутентификация

* Login (SSO / корпоративная БД)
* Восстановление доступа
* Переключение языка (RU / EN / LV — если нужно)

Регистрации нет.

---

# 2️⃣ Dashboard

Содержимое:

* Ближайшие встречи
* Быстрая кнопка “Создать сеанс”
* Мини-календарь
* Последние отчеты
* KPI (если роль позволяет)

Разный вид в зависимости от роли.

---

# 3️⃣ Планирование сеансов

Функции:

* Выбор даты/времени
* Тип встречи:

  * Hiring
  * Team call
* Выбор пресета AI-модели
* Приглашение участников
* Назначение руководителя / HR
* Статус встречи

Отображение:

* Календарь (месяц / неделя)
* Табличный список

---

# 4️⃣ Экран видеозвонка (Core Screen)

Обязательно добавить в промт:

* Видео-сетка участников
* Панель управления (микрофон, камера, запись)
* Индикатор активной AI-аналитики
* Кнопка завершения
* Статус обработки отчета после звонка

---

# 5️⃣ Отчеты (Hiring режим)

Содержимое отчета:

* Эмоциональный профиль
* Графики (radar chart, bar chart)
* AI-оценка соответствия
* Комментарии

---

## 🔒 Скрытое задание руководителя (важный момент)

Руководитель задаёт критерии:

* Стрессоустойчивость
* Лидерство
* Эмпатия
* Командность
* Самоконтроль

Эти критерии:

* Не видит кандидат
* Не видит HR
* Открываются только на финальном этапе
* Доступ только role = руководитель

UI-реализация:

* Отдельная вкладка "Требования"
* Блок скрыт/locked для остальных ролей

Это нужно чётко прописать — иначе ИИ не создаст систему ролей.

---

# 6️⃣ Командные звонки (без HR)

Цель — отслеживание KPI команды.

Метрики:

* Средний эмоциональный фон
* Индекс вовлеченности
* Индекс доминирования
* Индекс конфликтности
* Динамика по периодам
* Heatmap по участникам

Отчет группируется:

* По команде
* По проекту
* По периоду времени

HR к этому разделу доступа не имеет.

---

# 7️⃣ Конструктор пресетов AI

Доступ:

* Только Администратор
* Возможно Руководитель

Функции:

* Выбор модели (video / audio / combined)
* Настройка весов метрик
* Настройка порогов
* Сохранение пресета
* Применение к запланированному звонку

UI:

* Таблица пресетов
* Кнопка “Создать”
* Форма конфигурации

Это отдельный раздел навигации.

---

# 🔍 По поводу языков (3*)

Если это MVP — можно убрать мультиязычность.
Если цель — enterprise — оставить.

Мультиязычность усложняет:

* Layout
* Хранение текстов
* UI-состояния
