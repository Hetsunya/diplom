# UI для сервиса emeeting
## Сервис представляет из себя аналог meeting сервисов аля google meet, с внедренным ИИ для отслеживания и анализа эмоций, с последующим преобразованиемих в различные метрики и отбор персонала, с возможностью проводить просто тимколлы с приглащением участиноков команды и тд 
## ui должен быть исполнен лаконично с удобной навигацией, с переключениеммежду языками(3*)
1. должна быть аунтетификация с возможность восстановить аккаунт, без регистрации потому что корпоративная бд должна быть
2. возможность планровать сеансы, с отображением на календаре и на дешборде
3. просмотр отчетов, с проверкой задания от рукаводителя(1*), которое описывает необходимые эмоциональные качетва от кандидата, должно быть скрыто от всех до финального этапа
4. просмотр отчетов по групповым звонкам команд без участия как таковых hr специалистов, для отслеживания кпд(2*)
5. конструктор пресетов для настройки моделей и применине их к запланированным звонкам, можно вынести как отдельный пункт в задание, дабы не давать доступ кому попало
